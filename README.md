# Preoperative Pancreatic Stenting versus Direct Surgery: Surgical Safety Benefits in Robot-assisted Local Enucleation of Pancreatic Head Tumors

## 🧪 Pancreatic Duct Stenting Analysis Pipeline Overview

This repository contains code for statistical analysis of pancreatic duct stenting outcomes in patients undergoing pancreatic surgery.

The workflow includes data preprocessing, variable derivation, survival analysis, and regression modeling.

## ⚠️ Data Availability Statement

This repository contains analysis code only.

Patient-level data are not included due to institutional privacy regulations and ethical restrictions.

Data structure used in the scripts is illustrative and reconstructed for reproducibility purposes only, and does not represent any identifiable patient-level dataset.
